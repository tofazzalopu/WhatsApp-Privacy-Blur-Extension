# WhatsApp-Privacy-Blur-Extension
The WhatsApp Privacy Extension provides a comprehensive visual privacy layer for WhatsApp Web. It allows users to selectively blur sensitive information and control exactly what remains visible on their screen. The extension combines global privacy control, adjustable blur intensity, individual privacy toggles, and hover-to-reveal functionality for a flexible and user-friendly experience.

Core Privacy Controls
🔐 Global Blur Control

Users can turn the entire privacy protection system ON or OFF with a single toggle. When enabled, all selected privacy categories are automatically protected.

🎚️ Adjustable Blur Strength

A blur-strength slider allows users to customize the intensity of the privacy effect. Users can choose a lighter blur for convenient browsing or a stronger blur for increased privacy in public environments.

Individual Privacy Protection

The extension provides independent controls for the following 8 privacy categories:

👤 1. Contact Names

Blurs contact names displayed in the chat list and conversation header, preventing nearby viewers from easily identifying who the user is communicating with.

🖼️ 2. Profile Pictures

Blurs contact avatars and profile pictures throughout WhatsApp Web to reduce visual identification of contacts.

👥 3. Group Names & Pictures

Blurs group titles and group avatars together, protecting group identity and associated visual information.

💬 4. Message Previews

Blurs conversation snippets displayed in the chat list so private message previews cannot be easily read by people viewing the screen.

📝 5. Chat Messages

Blurs message text inside conversations, protecting the actual content of private chats while still allowing the user to interact normally with WhatsApp Web.

📎 6. Media & Attachments

Blurs images, videos, documents, and other media or attachment previews displayed in conversations, helping protect sensitive shared content.

⌨️ 7. Input Fields

Blurs text entered into WhatsApp message fields when the user is not actively interacting with the field, providing additional protection for typed information.

📩 8. Unread Message List

Protects unread-message information by limiting what is displayed in the unread message list. Instead of exposing the complete sender and message content, the interface can show only a limited portion of the information while keeping the rest hidden.

👁️ Hover-to-Reveal

Hover-to-reveal is always available for protected elements. Users can move the pointer over a blurred item or focus on it to temporarily reveal the underlying information.

This creates a practical privacy model:

Blur by default → Hover when needed → Automatically protect again when no longer viewed.

⚙️ Granular Privacy Settings

Rather than forcing users to blur everything, the extension provides individual switches for each privacy category. Users can create their own privacy configuration—for example:

Blur names and profile pictures but keep messages visible.
Blur messages and media while leaving contact information visible.
Enable every available privacy category for maximum screen privacy.
Disable individual protections when they are not needed.

The interface also displays the current number of enabled privacy controls, making the privacy configuration easy to understand at a glance.

Offices and workplaces
Universities and classrooms
Libraries and cafés
Public transportation or public spaces
Shared computers
Open-plan offices

Any environment where someone nearby can see the screen
🎯 Main Objective

The extension is designed around one principle:

Your WhatsApp remains usable, while sensitive information stays private from people looking at your screen.

It does not require users to close conversations or stop using WhatsApp Web. Instead, it provides a customizable visual privacy layer that lets users decide what should be hidden and when it should be revealed.
